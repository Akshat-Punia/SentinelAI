# Sentinel AI

AI-Powered Security, Identity & Risk Intelligence Platform.

## Overview
Sentinel AI is a cybersecurity platform designed to monitor security events, identify suspicious activities, manage user identities and permissions, and provide AI-powered risk analysis.

## Core Modules

1. Identity & Access Management (IAM)
2. Security Event Monitoring
3. Threat Detection Engine
4. Machine Learning Risk Engine
5. Generative AI Security Assistant
6. Analytics & Security Reporting

## Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- Machine Learning: Scikit-learn
- Generative AI: Groq API
- Deployment: Docker
